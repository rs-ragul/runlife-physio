# Runlife Physio — Specialized MPT Physiotherapy Network (Bangalore & Online)

**Tagline:** `REHAB · RECOVER · RUN`  
**Founder:** Dr. Vishal (PT)  
**Stack:** Next.js (App Router, TypeScript) • Tailwind CSS • Firebase Spark Free Tier (Firestore + Auth) • Nodemailer / Resend • Technical SEO (Dynamic Sitemap, Robots, Schema.org JSON-LD)

## Key Highlights
- **5 Dedicated MPT Specialty Hubs (`/services/[slug]`):** Orthopedic & MSK, Neurological, Sports & Running, Pediatric, and Gynecology / Women's Health.
- **18+ Dedicated Clinical Condition Guides (`/conditions/[slug]`):** Covering ACL/PCL, TKR/THR, Fractures, Sciatica, Stroke (CVA), Spinal Cord Injury, Guillain-Barré Syndrome (GBS), Parkinson's, MS, Running Injuries, S&C, Cerebral Palsy, Autism, GDD, Hydrocephalus, Spina Bifida, Muscular Dystrophy, Antenatal/Postnatal, and Pelvic Floor Rehab.
- **Interactive Anatomical Pain Map & 30-Second Smart Care Finder** on Homepage.
- **Bangalore Local SEO Hub (`/bangalore`)** + **4 Care Modes (`/care-modes`)**.
- **Full Backend + `/admin` Doctor Command Center:** Saves patient bookings & inquiries to Cloud Firestore, sends optional email alerts to `runlifephysio@gmail.com`, generates structured WhatsApp summaries to `+91 91876 79723`, and gives Dr. Vishal status management, clinical notes, 1-click patient WhatsApp, and CSV export.
